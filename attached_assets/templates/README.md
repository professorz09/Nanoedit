# Template preview thumbnails

Drop one 16:9 image per template style, named **exactly after the template id**.
The matching card then shows the real thumbnail instead of the emoji swatch.

Accepted: `.jpg` `.jpeg` `.png` `.webp`

| File name to use   | Template style                          |
|--------------------|-----------------------------------------|
| `mrbeast.jpg`      | MrBeast — high-energy, shocked face      |
| `mystery.jpg`      | Mystery / dark dramatic                   |
| `transformation.jpg` | Before → After transformation           |
| `finance.jpg`      | Finance / money comparison                |
| `adventure.jpg`    | Survival / adventure                      |
| `gaming.jpg`       | Gaming                                     |
| `podcast.jpg`      | Podcast / two-mic interview               |
| `tutorial.jpg`     | Tutorial / educational talking-head       |

Example: save a survival thumbnail as `adventure.jpg` here → the Adventure card shows it.
